# TASK-001 — Repository and TypeScript Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Establish a pinned, runnable JobHunter repository with strict native-ESM TypeScript, a help-only Commander entrypoint, separated normal/live Vitest configurations, and the approved ESLint/Prettier tooling without implementing product behavior.

**Architecture:** `src/cli.ts` owns only the Commander program factory and direct argument parsing. TypeScript emits only production source from `src/` into `dist/`; a separate no-emit test project typechecks tests and test configuration. Vitest, ESLint, and Prettier are independent developer-tool adapters configured at the repository root, and no runtime data/path service is introduced.

**Tech Stack:** Node.js `24.18.0`, pnpm `11.18.0`, TypeScript with native ESM/NodeNext, Commander.js, Vitest with V8 coverage, ESLint flat config with `typescript-eslint` and `eslint-config-prettier`, and Prettier.

## Global Constraints

- Use Node.js `24.18.0` and pnpm `11.18.0`.
- Declare `"engines": { "node": ">=24.18.0 <25" }` and `"packageManager": "pnpm@11.18.0"` in `package.json`.
- Use native ESM with `"type": "module"`, TypeScript `module: "NodeNext"`, and `moduleResolution: "NodeNext"`.
- Use strict TypeScript with `target: "ES2023"`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`, and `useUnknownInCatchVariables`.
- Emit production JavaScript, declarations, and source maps from `src/` to `dist/`.
- Keep CLI handlers thin and do not add product commands, prompts, path resolution, configuration, persistence, scraping, OpenAI, filtering, or scoring.
- Install only the TASK-001 foundation dependencies; do not install future-task product dependencies.
- Use Vitest; normal tests must exclude `tests/live/**`, and live tests must require explicit execution.
- Use ESLint’s official TypeScript/ESM initializer output without inferred project-specific rules.
- Integrate `typescript-eslint` and `eslint-config-prettier`.
- Use exactly these additional Prettier options: `printWidth: 100`, `singleQuote: true`, `trailingComma: "all"`, `endOfLine: "lf"`, and `arrowParens: "always"`.
- Do not store application data in the repository; preserve shared `docs/` files by removing the current broad `docs/` ignore rule.
- Do not add or remove direct dependencies outside this plan, and ask before any dependency change.
- Do not stage or commit without showing the current branch, files to stage, proposed Conventional Commit message, and verification results, then receiving explicit approval.

**Interfaces:**

- [ ] **Step 1: Write the foundation contract test before the CLI implementation**

Create `tests/foundation.test.ts` with:

```ts
import { mkdtempSync, readdirSync, rmSync } from 'node:fs';
import { tmpdir } from 'node:os';
import { join } from 'node:path';

import { describe, expect, it } from 'vitest';

import { createProgram } from '../src/cli.js';

describe('CLI foundation', () => {
  it('exposes help metadata without product commands', () => {
    const program = createProgram();
    const help = program.helpInformation();

    expect(help).toContain('Usage: jobhunter');
    expect(help).toContain('Local job discovery pipeline');
    expect(program.commands).toHaveLength(0);
  });

  it('does not create runtime files while constructing help', () => {
    const temporaryHome = mkdtempSync(join(tmpdir(), 'jobhunter-foundation-'));
    const before = readdirSync(temporaryHome);
    const previousEnvironment = {
      HOME: process.env.HOME,
      XDG_CONFIG_HOME: process.env.XDG_CONFIG_HOME,
      XDG_DATA_HOME: process.env.XDG_DATA_HOME,
      XDG_STATE_HOME: process.env.XDG_STATE_HOME,
      XDG_CACHE_HOME: process.env.XDG_CACHE_HOME,
    };

    process.env.HOME = temporaryHome;
    process.env.XDG_CONFIG_HOME = join(temporaryHome, 'config');
    process.env.XDG_DATA_HOME = join(temporaryHome, 'data');
    process.env.XDG_STATE_HOME = join(temporaryHome, 'state');
    process.env.XDG_CACHE_HOME = join(temporaryHome, 'cache');

    try {
      createProgram().helpInformation();
      expect(readdirSync(temporaryHome)).toEqual(before);
    } finally {
      if (previousEnvironment.HOME === undefined) delete process.env.HOME;
      else process.env.HOME = previousEnvironment.HOME;
      if (previousEnvironment.XDG_CONFIG_HOME === undefined) delete process.env.XDG_CONFIG_HOME;
      else process.env.XDG_CONFIG_HOME = previousEnvironment.XDG_CONFIG_HOME;
      if (previousEnvironment.XDG_DATA_HOME === undefined) delete process.env.XDG_DATA_HOME;
      else process.env.XDG_DATA_HOME = previousEnvironment.XDG_DATA_HOME;
      if (previousEnvironment.XDG_STATE_HOME === undefined) delete process.env.XDG_STATE_HOME;
      else process.env.XDG_STATE_HOME = previousEnvironment.XDG_STATE_HOME;
      if (previousEnvironment.XDG_CACHE_HOME === undefined) delete process.env.XDG_CACHE_HOME;
      else process.env.XDG_CACHE_HOME = previousEnvironment.XDG_CACHE_HOME;
      rmSync(temporaryHome, { recursive: true, force: true });
    }
  });
});
```

import { pathToFileURL } from 'node:url';

import { Command } from 'commander';

export function createProgram(): Command {

    .name('jobhunter')
    .description('Local job discovery pipeline');

}
